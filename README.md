# Vehicle Maintenance History Frontend

Frontend Vue 3 separado del backend Laravel.

## Requisitos

- Node.js 20+
- Backend Laravel corriendo en `http://127.0.0.1:8000`

## Instalacion

```bash
npm install
cp .env.example .env
npm run dev
```

Configura `VITE_API_BASE_URL` si el backend usa otra URL.
